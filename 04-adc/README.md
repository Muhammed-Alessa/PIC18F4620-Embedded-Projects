# 04 - ADC

PIC18F4620 projects focused on the 10-bit Analog-to-Digital Converter and practical analog measurements.

## Projects

1. LED Voltmeter
2. LCD Voltmeter
3. Precision LCD Voltmeter
4. LM35 Digital Thermometer

## Source Basis

This folder intentionally contains only ADC projects that are directly supported by the two Doğan Ibrahim books used for this repository.

- **LED Voltmeter** — based on Project 5.11, *PIC Microcontroller Projects in C: Basic to Advanced*.
- **LCD Voltmeter** — based on Project 5.12 in *PIC Microcontroller Projects in C: Basic to Advanced* and Project 6.8 in *Advanced PIC Microcontroller Projects in C*.
- **Precision LCD Voltmeter** — based on the "A More Accurate Display" fixed-point modification of the voltmeter in *Advanced PIC Microcontroller Projects in C*.
- **LM35 Digital Thermometer** — based on Project 5.15, *PIC Microcontroller Projects in C: Basic to Advanced*.

The project descriptions are paraphrased and the source code has been rewritten for the PIC18F4620 and current mikroC PRO for PIC conventions.

No unrelated ADC examples were added simply to increase the project count.

Circuit diagrams and real breadboard photographs can be added later to each project README.
