# LED Voltmeter

## Description

This project uses the PIC18F4620 ADC to measure an input voltage from 0 to 5 V on AN0. Five LEDs connected to PORTD indicate the voltage range in 1 V steps, from 0–1 V up to 4–5 V.

## Hardware

- PIC18F4620
- PICkit 3
- 5 LEDs
- 5 x 330 ohm resistors
- 10 kohm potentiometer or 0-5 V analog source
- 8 MHz crystal
- 2 x 22 pF capacitors
- 5 V power supply
