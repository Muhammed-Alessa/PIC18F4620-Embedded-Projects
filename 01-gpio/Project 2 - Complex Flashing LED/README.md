# Complex Flashing LED

## Description

This project connects one LED to RC0 of the PIC18F4620 and produces a repeating flash sequence. The LED flashes three times with short intervals, pauses for two seconds, and then repeats the pattern.

## Hardware

- PIC18F4620
- PICkit 3
- LED
- 330 ohm resistor
- 8 MHz crystal
- 2 x 22 pF capacitors
- 5 V power supply
