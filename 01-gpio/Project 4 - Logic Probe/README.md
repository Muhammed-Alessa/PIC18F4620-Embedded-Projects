# Logic Probe

## Description

This project uses RC0 as a digital probe input and two LEDs as logic indicators. A low input turns on the red LED, while a high input turns on the green LED.

## Hardware

- PIC18F4620
- PICkit 3
- Red LED
- Green LED
- 2 x 330 ohm resistors
- Probe wire
- 8 MHz crystal
- 2 x 22 pF capacitors
- 5 V power supply
