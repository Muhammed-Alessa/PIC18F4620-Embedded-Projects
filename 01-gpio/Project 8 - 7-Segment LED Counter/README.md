# 7-Segment LED Counter

## Description

This project connects a single common-anode 7-segment display to PORTC. The PIC18F4620 repeatedly counts from 0 to 9, showing each digit for one second before moving to the next.

## Hardware

- PIC18F4620
- PICkit 3
- 1 common-anode 7-segment display
- 7 x 330 ohm resistors
- 8 MHz crystal
- 2 x 22 pF capacitors
- 5 V power supply
