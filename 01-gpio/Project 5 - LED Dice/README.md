# LED Dice

## Description

This project builds an electronic dice using seven LEDs and a push button. When the button on RB0 is pressed, the PIC18F4620 selects a value from 1 to 6 and shows the matching dice pattern on PORTC for three seconds.

## Hardware

- PIC18F4620
- PICkit 3
- 7 LEDs
- 7 x 330 ohm resistors
- Push button
- 10 kohm pull-up resistor
- 8 MHz crystal
- 2 x 22 pF capacitors
- 5 V power supply
