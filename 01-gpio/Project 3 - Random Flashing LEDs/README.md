# Random Flashing LEDs

## Description

This project connects eight LEDs to PORTC and displays a different pseudo-random 8-bit pattern every second. Each generated byte directly controls the eight LEDs, producing continuously changing light patterns.

## Hardware

- PIC18F4620
- PICkit 3
- 8 LEDs
- 8 x 330 ohm resistors
- 8 MHz crystal
- 2 x 22 pF capacitors
- 5 V power supply
