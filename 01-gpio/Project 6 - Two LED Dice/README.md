# Two LED Dice

## Description

This project extends the electronic dice idea to two dice. A button press generates two values from 1 to 6, with the first dice shown by seven LEDs on PORTC and the second by seven LEDs on PORTD.

## Hardware

- PIC18F4620
- PICkit 3
- 14 LEDs
- 14 x 330 ohm resistors
- Push button
- 10 kohm pull-up resistor
- 8 MHz crystal
- 2 x 22 pF capacitors
- 5 V power supply
