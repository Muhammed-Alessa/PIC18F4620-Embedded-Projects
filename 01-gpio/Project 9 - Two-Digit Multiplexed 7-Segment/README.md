# Two-Digit Multiplexed 7-Segment

## Description

This project drives a two-digit common-cathode 7-segment display using multiplexing. PORTD supplies the segment pattern while RA0 and RA1 select the active digit, making the fixed value 25 appear continuously.

## Hardware

- PIC18F4620
- PICkit 3
- 2-digit common-cathode 7-segment display
- 7 x 330 ohm resistors
- 2 NPN transistors for digit switching
- 2 transistor base resistors
- 8 MHz crystal
- 2 x 22 pF capacitors
- 5 V power supply
