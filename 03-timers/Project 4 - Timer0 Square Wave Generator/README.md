# Timer0 Square Wave Generator

## Description

This project uses Timer0 interrupts to generate an accurate square wave on RC2. The output changes state every 500 microseconds, producing a square wave of approximately 1 kHz.

## Hardware

- PIC18F4620
- PICkit 3
- Oscilloscope or logic analyzer for testing
- 8 MHz crystal
- 2 x 22 pF capacitors
- 5 V power supply
