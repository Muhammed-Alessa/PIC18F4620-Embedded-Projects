# 03 - Timers

PIC18F4620 projects focused on the hardware timer/counter peripherals and practical timing applications.

## Projects

1. Timer0 Interrupt LED Blink
2. Timer1 Interrupt LED Blink
3. Timer0 External Pulse Counter
4. Timer0 Square Wave Generator
5. Frequency Counter with LCD
6. Reaction Timer with LCD

The first projects are small timer exercises based on the PIC18 timer concepts used throughout Doğan Ibrahim's books.

The Frequency Counter and Reaction Timer are adapted from application projects in *PIC Microcontroller Projects in C: Basic to Advanced*. Their descriptions and PIC18F4620 mikroC source code are newly written for this repository.

Circuit diagrams and real breadboard photographs can be added later to each project README.
