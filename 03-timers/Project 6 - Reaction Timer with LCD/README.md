# Reaction Timer with LCD

## Description

This project measures how quickly a push button is pressed after an LED turns on. After a changing delay, the LED is activated and Timer0 starts counting; pressing the button stops the timer and the measured reaction time is displayed in milliseconds on the LCD.

## Hardware

- PIC18F4620
- PICkit 3
- 16x2 HD44780-compatible LCD
- LED
- 330 ohm resistor
- Push button
- 10 kohm pull-up resistor
- 10 kohm potentiometer for LCD contrast
- 8 MHz crystal
- 2 x 22 pF capacitors
- 5 V power supply
