# Timer0 Interrupt LED Blink

## Description

This project uses Timer0 on the PIC18F4620 to generate a periodic interrupt. The timer overflows about every 500 ms, and the interrupt service routine toggles an LED connected to RD0.

## Hardware

- PIC18F4620
- PICkit 3
- LED
- 330 ohm resistor
- 8 MHz crystal
- 2 x 22 pF capacitors
- 5 V power supply
