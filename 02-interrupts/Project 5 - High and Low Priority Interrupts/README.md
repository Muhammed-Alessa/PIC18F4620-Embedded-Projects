# High and Low Priority Interrupts

## Description

This project uses two external interrupt sources to demonstrate PIC18 priority levels. INT1 on RB1 is assigned high priority and toggles RD0, while INT2 on RB2 is assigned low priority and toggles RD1.

## Hardware

- PIC18F4620
- PICkit 3
- 2 push buttons or digital pulse sources
- 2 x 10 kohm resistors
- 2 LEDs
- 2 x 330 ohm resistors
- 8 MHz crystal
- 2 x 22 pF capacitors
- 5 V power supply
