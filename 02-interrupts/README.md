# 02 - Interrupts

PIC18F4620 projects focused on external interrupts, interrupt-on-change, and the PIC18 high/low priority interrupt system.

## Projects

1. INT0 External Interrupt LED Toggle
2. INT1 High-Priority Interrupt
3. INT1 Low-Priority Interrupt
4. PORTB Change Interrupt
5. High and Low Priority Interrupts
6. External Interrupt Event Counter

The interrupt concepts are based on the PIC18 material and projects in Doğan Ibrahim's books. The descriptions and PIC18F4620 mikroC source code in this folder are newly written for this repository.

The final event-counter project combines INT0 external interrupts with Timer0 interrupts so event counting and display refreshing can operate independently.

Circuit diagrams and real breadboard photographs can be added later to each project README.
