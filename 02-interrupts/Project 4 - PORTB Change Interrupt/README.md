# PORTB Change Interrupt

## Description

This project demonstrates the PORTB change interrupt available on RB4 through RB7. A change on RB4 generates an interrupt, and the interrupt service routine toggles an LED connected to RD0.

## Hardware

- PIC18F4620
- PICkit 3
- Push button
- 10 kohm pull-up resistor
- LED
- 330 ohm resistor
- 8 MHz crystal
- 2 x 22 pF capacitors
- 5 V power supply
