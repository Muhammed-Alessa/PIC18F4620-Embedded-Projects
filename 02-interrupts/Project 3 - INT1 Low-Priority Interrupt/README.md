# INT1 Low-Priority Interrupt

## Description

This project configures INT1 on RB1 as a low-priority interrupt. When a rising edge is detected, the low-priority interrupt service routine toggles an LED connected to RD0.

## Hardware

- PIC18F4620
- PICkit 3
- Push button or digital pulse source
- 10 kohm resistor
- LED
- 330 ohm resistor
- 8 MHz crystal
- 2 x 22 pF capacitors
- 5 V power supply
